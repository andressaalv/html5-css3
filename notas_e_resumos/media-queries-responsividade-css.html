📘 Folha de Estudos – Media Queries (Responsividade)

🔹 O que são Media Queries?

Media Queries são regras CSS que aplicam estilos diferentes com base nas características da tela: largura, altura, orientação, resolução etc.

Elas tornam seu layout responsivo, ou seja, adaptável a celulares, tablets e monitores.

🔹 Sintaxe Básica

@media (condição) {
  /* estilos aqui */
}

Exemplo:

@media (max-width: 600px) {
  body {
    background-color: lightblue;
  }
}

👉 Aplica o fundo azul claro quando a tela tiver 600px ou menos.

🔹 Tipos Comuns de Condições

CondiçãoDescriçãoExemplo
max-width Aplica quando a tela tem até X pixels @media (max-width: 768px)
min-width Aplica a partir de X pixels @media (min-width: 1024px)
orientation Verifica orientação: retrato ou paisagem @media (orientation: portrait)
hover, pointer Verifica se o dispositivo tem ponteiro (mouse, touch, etc) @media (hover: hover)

🔹 Breakpoints Comuns

Breakpoints são larguras de tela onde o layout muda:

DispositivoBreakpoint
Celular pequenomax-width: 480px
Celular médiomax-width: 768px
Tabletmax-width: 1024px
Notebook/Desktopmin-width: 1025px

📊 Quando Usar Media Queries

  • Para ajustar tamanhos de fonte, margens e paddings em telas pequenas.
  • Para reorganizar colunas em layouts (ex: 3 colunas viram 1 no celular).
  • Para mostrar ou esconder elementos em certos tamanhos de tela.

🧠 Dicas Rápidas

  • Escreva o layout base primeiro (mobile-first), depois adicione min-width.
  • Use unidades relativas (em, rem, %) dentro das media queries para melhor responsividade.
  • Evite ter muitas media queries pequenas. Agrupe estilos quando possível.
