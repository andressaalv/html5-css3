📘 Folha de Estudos – CSS Grid Layout

🔹 O que é CSS Grid?

O CSS Grid Layout é um sistema bidimensional de layout, perfeito para construir grades com linhas e colunas.

.container {
  display: grid;
}

🔹 Criando Colunas e Linhas

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: auto auto;
}
  • fr = fração do espaço disponível
  • auto = altura ou largura automática com base no conteúdo

🔹 Espaçamento entre itens

.container {
  gap: 10px;
}

Ou se quiser espaçamento separado:

row-gap: 20px;
column-gap: 10px;

🔹 Posicionando Itens

PropriedadeExemploDescrição
grid-column2 / 4Item começa na coluna 2 e vai até antes da 4
grid-row1 / 3Item ocupa da linha 1 até antes da 3
grid-area1 / 2 / 3 / 4Atalho: linha-início / coluna-início / linha-fim / coluna-fim

🔹 Nomeando áreas

.container {
  display: grid;
  grid-template-areas:
    "header header"
    "menu content"
    "footer footer";
}
.header  { grid-area: header; }
.menu    { grid-area: menu; }
.content { grid-area: content; }
.footer  { grid-area: footer; }

🔹 Unidades úteis

  • fr → fração
  • auto → tamanho do conteúdo
  • minmax(min, max) → define limites
  • repeat(n, valor) → repete padrão
grid-template-columns: repeat(3, 1fr);
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

🔹 Alinhamentos Globais

PropriedadeFunção
justify-itemsAlinha conteúdo horizontalmente
align-itemsAlinha verticalmente
place-itemsAtalho: align + justify

🧠 Dicas Rápidas

  • Use grid-template-areas para layouts mais descritivos.
  • Para layout responsivo, combine grid + media queries.
  • Use auto-fit ou auto-fill com minmax para criar colunas fluidas.
