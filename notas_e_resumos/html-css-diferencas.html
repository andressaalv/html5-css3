📘 Folha de Estudos – Diferença entre HTML e CSS

🔹 Conceito Básico

HTMLCSS
Hipertexto para estruturar conteúdoLinguagem de estilo para aparência
Cria e organiza os elementosDefine cor, tamanho, espaçamento, etc.
Usa <tags>Usa seletores e propriedades

🔹 Exemplos

HTML:

<h1>Título</h1>
<p>Parágrafo de texto</p>

CSS:

h1 {
  color: blue;
  font-size: 24px;
}

🔹 Resumo Rápido

  • 💡 HTML = O que está na página
  • 🎨 CSS = Como a página aparece
  • 📚 HTML é obrigatório; CSS é opcional (mas essencial para estilo!)
