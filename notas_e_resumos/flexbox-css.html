📘 Folha de Estudos – CSS Flexbox

🔹 O que é Flexbox?

O Flexbox (caixa flexível) é um modelo de layout unidimensional do CSS que organiza elementos em linha ou coluna com facilidade.

.container {
  display: flex;
}

🔹 Direção Principal (flex-direction)

ValorDescrição
rowItens em linha (padrão)
row-reverseLinha invertida
columnItens em coluna
column-reverseColuna invertida

🔹 Alinhamento Principal (justify-content)

ValorAlinhamento na direção principal
flex-startInício do container
centerCentralizado
flex-endFinal do container
space-betweenEspaço entre os itens
space-aroundEspaços iguais em volta
space-evenlyEspaços totalmente iguais

🔹 Alinhamento Cruzado (align-items)

ValorAlinhamento na direção perpendicular
stretchPreenche altura total (padrão)
flex-startInício da cruz
centerCentralizado
flex-endFinal da cruz
baselineAlinha pela linha de base do texto

🔹 Quebra de Linha (flex-wrap)

Por padrão, o Flexbox não quebra linha. Use:

.container {
  flex-wrap: wrap;
}

Outros valores: nowrap (padrão), wrap-reverse

🔹 Atalhos úteis

gap: controla espaçamento entre itens

.container {
  display: flex;
  gap: 1rem;
}

🔹 Propriedades nos Itens (Filhos)

PropriedadeFunção
orderDefine a ordem de exibição (ex: order: 2)
flex-growQuanto o item cresce proporcionalmente
flex-shrinkQuanto o item encolhe se necessário
flex-basisTamanho base do item
align-selfSobrescreve o align-items para um item só

📊 Exemplo Prático

.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 10px;
}

🧠 Dicas Rápidas

  • Flexbox é ótimo para menu horizontal, alinhamento central, distribuição de colunas.
  • Use align-items: center e justify-content: center para centralização total.
  • Para colunas responsivas, combine Flexbox com wrap + width%.
