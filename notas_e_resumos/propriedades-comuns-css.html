📘 Folha de Estudos – Propriedades CSS Comuns

🔹 Box Model (Modelo de Caixa)

Todo elemento HTML é uma caixa com:

  • margin – Espaço externo
  • border – Borda
  • padding – Espaço interno
  • content – O conteúdo em si

🔹 Margem e Espaçamento

PropriedadeDescrição
marginEspaço externo (pode usar valores individuais: top, right, bottom, left)
paddingEspaço interno (mesma lógica)
gapEspaço entre elementos (em Flexbox e Grid)
margin: 20px 10px 5px 0;
/* top | right | bottom | left */

🔹 Largura e Altura

width: 100%;
height: 200px;
max-width: 1200px;
min-height: 300px;

🔹 Bordas e Arredondamento

border: 1px solid #333;
border-radius: 8px;

border-radius permite cantos arredondados.

🔹 Cor e Fundo

color: #333;
background-color: #f9f9f9;
background-image: url("fundo.jpg");
background-size: cover;

🔹 Tipografia

font-size: 16px;
font-family: Arial, sans-serif;
font-weight: bold;
line-height: 1.5;
text-align: center;
text-transform: uppercase;

🔹 Display e Visibilidade

ValorDescrição
blockO elemento ocupa uma linha inteira
inlineFica na mesma linha que outros
inline-blockComo inline, mas permite altura/largura
noneOculta o elemento
flexInicia Flexbox
gridInicia Grid

🔹 Posicionamento

ValorDescrição
staticPosição padrão
relativeRelativo à posição original
absoluteRelativo ao primeiro pai com position
fixedFixado na tela
stickyFica preso após scroll
position: absolute;
top: 10px;
left: 0;

🔹 Outros úteis

  • box-shadow – sombra externa
  • opacity – opacidade do elemento
  • z-index – profundidade (pilha de camadas)
  • overflow – rolagem ou esconder conteúdo excedente
box-shadow: 2px 2px 8px rgba(0,0,0,0.2);
opacity: 0.8;
overflow: hidden;

🧠 Dicas Rápidas

  • Use * { box-sizing: border-box; } no início do CSS para facilitar controle do tamanho total.
  • Combine padding + margin corretamente para espaçamentos consistentes.
  • Use rem para tamanhos de fonte consistentes.
